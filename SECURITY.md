# Security policy

This repository holds a static profile page (Markdown, images and two text files). It runs no code,
so the realistic problems here are a link that points somewhere unsafe, or someone impersonating
Syed Ahmer Shah.

## Reporting

- **This repository**: use [Report a vulnerability](https://github.com/ahmershahdev/ahmershahdev/security/advisories/new)
  (private) or email support@ahmershah.dev.
- **MarketClock or HolidayOps**: report it privately in that project's repository under
  **Security > Report a vulnerability**, or email support@ahmershah.dev.
- **Zovita+, BookMyMovie, GleanGrid or Commerza**: these repositories are archived, so email
  support@ahmershah.dev.
- Please do not open a public issue for a vulnerability.
- **Impersonation**: the official profiles are the ones listed on [ahmershah.dev](https://ahmershah.dev)
  and in this README. Report anything else claiming to be Syed Ahmer Shah to support@ahmershah.dev.

Include what you found, where, and the steps to reproduce it. You can expect a reply within a few
days. Please give a reasonable time for a fix before any disclosure.
