# Contributing

This repository is the GitHub profile page of Syed Ahmer Shah. It is personal, so it does not take
feature contributions, but corrections are welcome.

## What helps

- A broken link, a badge or logo that does not render, or an image that fails to load
- A number or fact that no longer matches [ahmershah.dev](https://ahmershah.dev)
- A typo, or an image without a useful `alt` text

Open an [issue](https://github.com/ahmershahdev/ahmershahdev/issues) that names the section and
what you saw. A screenshot helps for rendering problems.

## Pull requests

Small fixes (links, typos, alt text) are fine as a pull request. Keep in mind:

- [ahmershah.dev](https://ahmershah.dev) is the source of truth. Projects, certificates, skill
  levels and counts are copied from it, never invented here.
- `llms.txt` and `llms-full.txt` are copied unchanged from the live site; do not edit them by hand.
- `googlefd88f5d13cd71b69.html` is a Google Search Console verification file; leave it in place.
- No emojis. Badge logos use Shields.io `logo=` names, or a base64 data URI when the brand is not in
  Simple Icons.

## Anything else

For projects, hiring or questions about the work itself, use
[ahmershah.dev/#contact](https://ahmershah.dev/#contact) or support@ahmershah.dev. Bugs in one of
the projects belong in that project's own repository.
